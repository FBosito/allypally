# allypally

Single-Page-Webseite, optimiert für Smartphones, gehostet über GitHub Pages.

## Struktur

- `index.html` – Einstiegsseite
- `css/style.css` – Styles (mobile-first, Dark Mode)
- `js/app.js` – Logik

## Lokal testen

```
python -m http.server 8000
```

Dann http://localhost:8000 öffnen.

## Deployment

Repo auf GitHub pushen → Settings → Pages → Branch `main`, Ordner `/ (root)`.
